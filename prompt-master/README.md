# Prompt Master

Turns a rough prompt into a clearer, stronger one before you send it.

Type a rough prompt in the prompt box, then press the **✨ Prompt Master** button in the band just above the prompt (or run `/prompt-master`). The draft is rewritten in place by Claude Sonnet, keeping your intent, facts and constraints while making the goal, context and expected output explicit. Nothing is sent: review the result, edit it, then send. **Undo** restores your original draft until you send.
