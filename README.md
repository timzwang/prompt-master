# Prompt Master

A Claude Code mod that rewrites your rough prompt into a clearer, stronger one before you send it.

Type a rough prompt, then press **✨ Prompt Master** above the prompt box (or run `/prompt-master`). Your draft is rewritten in place; nothing is sent until you send it. **Undo** restores the original.

## Install

```
/plugin marketplace add <owner>/prompt-master
/plugin install prompt-master@local-mods
```
